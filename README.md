## About this site

Hand-built with plain HTML, CSS and JavaScript (no framework), and hosted on GitHub Pages. The design concept, "Uplink", treats the portfolio as a labelled network rack: patch-panel navigation, rack-unit project cards, a `traceroute` career timeline and cable-label skills. It supports light and dark themes and works on phones.

To run it locally, open `index.html` in a browser.
