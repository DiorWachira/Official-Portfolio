A service desk where every ticket races a visible SLA clock.

Developer tool · CLI + web + AI

RepoLens

A health check for any GitHub repository: eight checks, one score, and an AI examiner to talk it through.

Paste a public repo URL and RepoLens downloads the archive and audits README quality, licensing, tests, CI, TODO debt, oversized files and hardcoded secrets. It then writes a prescription with a verify command for every fix. The core is pure Python standard library with zero dependencies, and it doubles as a CLI and a CI gate.

  • Zero-dependency core: text and JSON reports, with exit codes built for CI (--strict)
  • The Examiner: an optional Gemini advisor with a model fallback chain, per-client rate limits and an offline deterministic mode
  • Hardened ingestion: archive size, expansion and entry-count limits, plus job timeouts and recovery after a restart
  • Verified UI: Playwright tests at desktop and phone widths, and a status palette validated for colour-vision deficiency

Final-year capstone · AI / ML

JobBridge

Matching Kenyan job seekers to roles on what they can do, not on which keywords they typed.

JobBridge is a hybrid AI matching and recommendation engine for workforce placement in Kenya, now running live in production. It combines rule-based eligibility, semantic similarity and a predictive ranking model, and a skill graph explains why a candidate matches and which skills they are missing. Hiring outcomes feed back to retrain the model.

  • NLP parsing of CVs and job descriptions into a knowledge graph of skills and roles
  • Explainable matches: matched and missing skills, with model provenance stored on every evaluation
  • ML discipline: a validated model contract that checks training and serving feature parity
  • Security: authenticator-app two-step verification (RFC 6238), hashed recovery codes, encrypted secrets and Google sign-in
